# Additional control for the six-pair challenge

The original seven-operation fixture contained two false permissions from the keyword rule. An exploratory change fitted after inspecting those errors also gets seven of seven on that fixture. The change keeps the repository keyword decision unless the public operation description contains an explicit negation of deduplication. The case-insensitive expression is `\b(?:no|not|without)\s+(?:\w+\s+){0,2}dedup\w*\b`.

Use the identical rule on both new fixtures. Score all twelve operations and the six pairs on which both decisions are correct. Publish the rule, fixtures, code and protocol before calling Muse. Report its origin and all controls even when they tie or beat Muse. A simple rule fitted to these authored examples is an exploratory comparator.
