Methodology, limitations and provenance

CrashLab is a hackathon research-engineering prototype, not a hosted arbitrary-contract service. The browser walkthrough plays recorded/saved local experiments; only the developer's local CLI uses Meta inference and executes HTTP faults. The first Muse run and the later guarded Muse run are distinct, not a paired controlled study. Illustrated console wording is a condensed presentation of the verified operation sequence, not raw model output. The separately recorded deterministic counterfactual blocks a second write by construction. The policy reference labels and operation contracts were written by the experiment author. None of these observations establish a statistically powered model ranking, a universal guarantee of exactly-once effects, or a new research method.

Earlier StateProof Lab prebuild material was removed from the current tree; Git history is preserved and PROVENANCE.md explains chronology. The independent oracle counts committed SQLite rows and cannot be read by the agent. Prior art includes LIMBO, established idempotency strategies, and agent chaos evaluations.
